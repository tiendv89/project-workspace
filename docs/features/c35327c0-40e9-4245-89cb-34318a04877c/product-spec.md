  "content": "# Product Spec — Smart Grocery List\n\n## Overview\n\nA mobile-friendly web app that helps households manage their grocery shopping by automatically suggesting items based on past purchase history and current pantry levels.\n\n## Problem\n\nFamilies frequently forget to buy essential items, overbuy things they already have, and waste time manually writing the same lists week after week. There is no lightweight tool that learns household habits and proactively surfaces what to buy.\n\n## Goals\n\n- Reduce forgotten items on grocery trips by 80%\n- Cut duplicate purchases by surfacing pantry inventory before checkout\n- Save users 10+ minutes per week on list preparation\n\n## Non-Goals\n\n- Integration with grocery store ordering / delivery\n- Barcode scanning or receipt OCR (future phase)\n- Multi-household sharing (future phase)\n\n## Users\n\n| Persona | Description |\n|---|---|\n| Primary shopper | Adult responsible for household grocery runs, 1–3 times per week |\n| Secondary member | Partner or family member who adds items but does not usually shop |\n\n## User Stories\n\n1. As a primary shopper, I want to see a suggested grocery list every Sunday morning so I can review and approve it before heading to the store.\n2. As a secondary member, I want to add an item to the shared list from my phone in under 10 seconds.\n3. As a primary shopper, I want to mark items as \"already have\" so they are removed from the current list without being forgotten for next week.\n4. As a primary shopper, I want to see items grouped by store section (produce, dairy, meat, etc.) so I can shop efficiently.\n\n## Features\n\n### Core (v1)\n\n- **Smart List Generation** — weekly suggested list derived from a rolling 8-week purchase history\n- **Manual Add / Remove** — any household member can add or remove items in real time\n- **Section Grouping** — items auto-categorised into store sections (produce, dairy, bakery, frozen, household)\n- **Done / Have It** — checkbox per item; \"have it\" snoozes the item for one week, \"done\" marks it purchased\n- **Push Notifications** — reminder at a configurable day/time each week (default Sunday 9 am)\n\n### Out of Scope for v1\n\n- Barcode scanning\n- Recipe-to-list import\n- Price tracking\n\n## Success Metrics\n\n| Metric | Target |\n|---|---|\n| Weekly active households | 500 within 3 months of launch |\n| Items forgotten per trip (self-reported) | < 1 on average |\n| List prep time (self-reported) | ≤ 5 minutes |\n| Day-7 retention | ≥ 60% |\n\n## Design Constraints\n\n- Must work offline (service worker cache) — shoppers are often in stores with poor connectivity\n- Mobile-first; desktop is a nice-to-have\n- No account required for single-user mode; optional sign-in for multi-member households\n\n## Open Questions\n\n1. Should the suggestion algorithm use a simple frequency model or an ML-based approach for v1?\n2. What is the preferred push notification provider (FCM / APNs / web push)?\n3. How do we handle households that start fresh with no history?\n"
