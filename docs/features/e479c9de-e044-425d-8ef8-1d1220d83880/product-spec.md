# Product Specification

## Feature
- Feature ID: `test-feaature-3`
- Title: SkillSwap — Peer-to-Peer Skill Exchange Network

## Problem
Millions of people have valuable skills they'd be willing to teach, but can't afford to hire instructors for skills they want to learn. Traditional online learning platforms are transactional and one-directional — you pay for a course and consume it passively. There is no platform that facilitates a true two-way exchange where someone who knows graphic design can trade lessons with someone who knows guitar, without money changing hands. The result is that skill development remains expensive and inaccessible for people who have time and talent but not disposable income.

## Goals
- Allow users to list skills they can teach and skills they want to learn, forming a personal skill profile
- Match users with compatible swap partners using a compatibility score (overlapping teach/learn pairs, availability, location preference)
- Support both local in-person and remote (video call) skill sessions, with scheduling handled inside the app
- Provide a structured session format: agreed session goals, a shared notes space, and a mutual completion confirmation
- Enable users to rate and review swap partners after each session to build reputation scores
- Include a "Skill Credit" system as a fallback for non-reciprocal swaps — teach someone and earn credits redeemable with any other user on the platform
- Send weekly match suggestions to users who haven't scheduled a session in 14+ days to re-engage them

## Non-goals
- No monetary transactions — this is a pure skill-exchange and credit system, not a paid tutoring marketplace
- No live video hosting inside the app — sessions use an external link (Zoom, Google Meet) provided by one party
- No AI-generated lesson plans or curriculum suggestions in v1
- No enterprise or corporate team accounts in this phase — individual users only
- No native mobile app in v1 — responsive web only
