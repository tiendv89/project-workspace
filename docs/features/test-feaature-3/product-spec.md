# Product Specification

## Feature
- Feature ID: `test-feaature-3`
- Title: RepQueue — Gym Session Planner & Workout Progress Tracker

## Problem
Gym-goers — from beginners to seasoned lifters — struggle to maintain structured, progressive training programs. Most people either follow a random assortment of exercises with no progression logic, or buy expensive coaching they don't need. Free alternatives (spreadsheets, notes apps) require too much manual effort and offer no intelligence. The result: people plateau early, lose motivation, and quit. There is no lightweight, intelligent tool that sits between "random workouts" and "expensive personal trainer" and helps individuals apply progressive overload consistently.

## Goals
- Allow users to build custom workout programs by selecting exercises from a built-in library (500+ exercises with video demos and muscle-group tags)
- Auto-generate progressive overload suggestions each session based on the user's logged history (e.g. "last week you did 3×8 @ 60kg — try 3×8 @ 62.5kg today")
- Log each set in real time during a workout with a minimal, one-tap interface designed for use with sweaty hands in a gym environment
- Track personal records (PRs) per exercise and notify the user when they hit a new PR mid-session
- Provide a visual progress dashboard showing strength trends per muscle group over 4, 8, and 12-week windows
- Support rest timer with configurable duration that auto-starts between sets and sends a notification when it's done
- Allow users to duplicate, modify, and share workout programs via a link (view-only for the recipient)

## Non-goals
- No AI-generated full training plans — program creation is always user-driven, with AI only suggesting weight/rep progression
- No nutrition tracking, meal planning, or calorie counting
- No live coaching, video feedback, or form analysis
- No integration with wearables (Apple Watch, Garmin, Whoop) in v1
- No marketplace or monetization of user-created programs in this phase
